# avatar-site# Avatar Landing Page

تصميم واجهة Landing Page مستوحاة من فيلم Avatar باستخدام HTML و CSS.

## التقنيات المستخدمة:
- HTML5
- CSS3
- Flexbox
- Hover Effects
- Gradients

## المميزات:
- تصميم عصري ومتناسق
- تجربة مستخدم بسيطة وسلسة
- قابل للتطوير وإضافة أقسام جديدة
